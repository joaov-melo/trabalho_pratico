Linguagem escolhida: C++
g++ main.cpp -o main
./main
Digite um número de 1 a 6 para escolher um dos 5 modos ou para sair.
Caso escolha o 1 ou o 2, digite um número de 1 a 4 para escolher a base de origem, e um outro número de 1 a 3 para a base destino. Também digite o número que será convertido.
Caso escolha o 3, certifique-se de ter criado o entrada.csv com as formatações corretas.
Caso escolha o 4, digite um número de 1 a 5 para determinar o nível de dificuldade.
Caso escolha o 5, digite o número de bits desejado.
E, caso escolha o 6, você sairá do sistema.
Limitações: Se uma letra for digitada como escolha de modo ou como escolha de base de origem/destino, o código fica em loop.
Comando de teste: g++ src/testes.cpp -o testes && ./testes
